# Marianne font assets

The regular, medium, and bold WOFF2 files come from `@gouvfr/dsfr` 1.15.4 (`dist/fonts/`). The extra-bold WOFF2 file comes from `@gouvfr-lasuite/ui-kit` 0.28.1, the same package and version used by Conversations.

The upstream DSFR license and usage conditions are preserved in `LICENSE.md`. These assets are used only for the opt-in DSFR editor theme in the French administration context.
